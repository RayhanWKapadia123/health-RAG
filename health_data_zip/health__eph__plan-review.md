# Commercial Plan Review Metrics Report

*Health > EPH > Commercial Plan Review*

Monthly metrics for plan reviews completed by the Commercial Plan Review program can be found below. The reviews include plans for construction of commercial onsite sewage systems, campgrounds, mobile home communities, agricultural labor camps and youth camps. The first plans submitted with the application for construction are initial plans. Revised plans are those that are submitted in response to a request by the program for revisions and/or additional information.

The metrics show the number of initial and revised plans reviewed along with the average number of days it took the program to complete these reviews each month. The percent of initial plan reviews completed in 30 days or fewer and the percent of revised plans reviewed completed in 15 days or fewer are also provided to show overall compliance with the maximum number of days the program has to complete reviews as set by Indiana Code.
