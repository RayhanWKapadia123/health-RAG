# Hospital Respiratory Data

The National Healthcare Safety Network (NHSN) has released [guidance](https://www.cdc.gov/nhsn/psc/hospital-respiratory-reporting.html) regarding hospital data reporting requirements that changed effective November 1, 2024.

The two primary changes are:

- Admission Data Elements, Capacity Elements and Clinical elements. There is an optional supplies section
- Reporting can be submitted daily or by Tuesday of the following week

### EMResource Response Hospital User Training

[EMResource](https://emresource.juvare.com/login) is an emergency resource management that optimizes real-time communication to enhance response to daily medical emergencies. EMResource is used by healthcare, public health, first responders, and other healthcare and government agencies. This system is utilized to monitor and notify changes in resource statuses such as diversions, EOC activations, resource availability and other information. The data inputted into this system will provide IDOH and healthcare coalitions with up-to-date data on capacity and needs.
